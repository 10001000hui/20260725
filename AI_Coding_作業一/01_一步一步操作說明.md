# 作業一逐步操作：建築學生作品與學習紀錄網站

## 1. 確認作業目標

使用 Next.js 製作可正常瀏覽的網站，透過 GitHub 保存版本，再部署至 Vercel。最後繳交公開網址與簡短作品說明。

本次作品「築跡 Studio Notes」以建築學生為主題，整理建築設計、模型製作、BIM、透視表現與 3D 列印學習。所有作品均為課程示範內容，不冒用你未提供的實際作品。

## 2. 打開已完成的專案

建立記錄（已完成，不要在現有專案上重複執行）：使用 `npx create-next-app@latest architecture-portfolio --ts --tailwind --eslint --app --src-dir --use-npm --no-react-compiler --import-alias "@/*" --yes` 建立 Next.js，再修改 `src/app/page.tsx`、`layout.tsx`、`globals.css` 並在 `public/images` 加入示意圖。

不用重新建立專案。將這個作業資料夾下載或解壓縮後，用 VS Code 的「檔案 → 開啟資料夾」，選取 `architecture-portfolio`。

如果從 GitHub 取得成果，可在終端機執行：

```bash
git clone --branch ai-coding-assignment-1 https://github.com/10001000hui/20260725.git
cd 20260725
cd AI_Coding_作業一
cd architecture-portfolio
```

注意要使用作業分支；`main` 是原本的 Python 專案。

## 3. 準備 Node.js 與安裝依賴

安裝 Node.js 24 LTS。VS Code 選「終端機 → 新增終端機」，確認目前資料夾內看得到 `package.json`。

```bash
node --version
npm --version
npm ci
```

`npm ci` 使用已附的 lockfile 安裝一致版本。不要刪除 `package-lock.json`。本次實測環境是 Node.js 24.19.0、Next.js 16.3.8。

## 4. 開啟網站

```bash
npm run dev
```

在自己的電腦上，以瀏覽器開啟終端機提供的開發網址，通常是 `http://localhost:3000`。此網址僅供本機使用，不可作為作業公開網址。

保持終端機開啟。停止網站時，在該終端機按 Ctrl+C。

## 5. 親自測試畫面與互動

1. 首頁能看到「在空間裡思考，在日常裡築跡」與建築示意圖。
2. 點擊「走進我的作品」，頁面會移到作品區。
3. 點「建築設計」會顯示 2 件；「模型製作」2 件；BIM 與透視表現各 1 件。
4. 搜尋 `Revit`，只會留下 BIM 作品；搜尋不存在的文字會顯示空結果提示。
5. 點「查看作品」開啟詳細介紹。按右上角 × 或鍵盤 Escape 關閉。
6. 點作品旁的 ☆，加入收藏；重新整理，再點「我的收藏」，作品仍保留。
7. 再點 ★ 可取消收藏。收藏只留在目前瀏覽器，不會同步到其他裝置。
8. 開啟學習資源會在新分頁瀏覽；考試資訊應另外核對考選部公告。
9. 按 F12，開啟裝置模擬工具，檢查手機和電腦版沒有橫向溢出、文字遮擋與圖片破圖。

## 6. 換成自己的建築作品（可自行延伸）

網站已可使用；目前圖片是原創建築概念示意圖。若你希望展示自己的作品：

1. 將作品照片放入 `public/images`，使用簡單英文檔名，例如 `my-model.jpg`。
2. 打開 `src/app/page.tsx`，找到 `projects` 陣列。
3. 修改 `title`、`subtitle`、`category`、`year`、`description`、`process` 和 `tools`。
4. 替換卡片及彈窗的圖片路徑；目前兩處皆使用 `.svg`，改成你的圖片副檔名。
5. 修改關於本站文字。只有已替換為真實作品後，才移除示範作品提示。
6. 儲存後回到瀏覽器，確認畫面更新。

使用自己拍攝或有授權的素材，避免直接複製參考網站的照片。

## 7. 正式建置驗證

停止開發伺服器，再執行：

```bash
npm run lint
npm run build
npm run start
```

`npm run build` 成功後，再用正式伺服器測試一次。這次雲端實測的 lint、TypeScript 與正式建置均通過。

進階瀏覽器測試：雲端已有 Chromium，可在另一個終端機執行 `npm run test:e2e`。其他電腦的瀏覽器設定請參閱專案 README。附帶的 `驗證資料` 已保存這次 8 項測試結果。

## 10. 部署正式網站

確認終端機的目前目錄是 `architecture-portfolio`，執行：

```bash
npx vercel --prod
```

第一次部署可能詢問以下事項（實際文字可能隨 CLI 版本不同）：

1. 是否設定與部署：選 Yes。
2. 所屬帳號／Team：選你自己的帳號。
3. 是否連結既有專案：第一次選 No。
4. 專案名稱：可用 `studio-notes-10001000hui`，重名則換其他名稱。
5. 專案目錄：保持 `./`，因為你已在網站目錄中。
6. 偵測框架：應顯示 Next.js。不要選其他框架。
7. Build Command 使用 `npm run build`；Output Directory 使用框架預設，不需手動指定。

等待建置與部署成功，複製終端機或 Vercel Dashboard 顯示的 Production 公開網址。

若使用 Vercel 網頁匯入 GitHub，請選此作業分支並將 Root Directory 設為 `AI_Coding_作業一/architecture-portfolio`。若介面無法在首次匯入前指定分支，優先使用上述 CLI 部署，避免把原本 Python 的 main 分支當作 Next.js 專案。

1. 開啟瀏覽器無痕視窗，貼上真正的 Production 網址。
